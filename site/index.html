A little more together.

Bayit is a warm home app for the whole family: today’s plan, the calendar, tasks and routines, shopping, the kids’ heroes, money and a Telegram bot. Everyone sees what they should, and nothing more.

Everything a home juggles.

One shared place for the whole family, in Hebrew or English, on phone, tablet and desktop, in light or night.

Today

The family’s agenda, little things to do and the kids’ routines on one calm page you arrange yourself.

A family bot of your own.

Connect your own Telegram bot and each person links their own chat. It speaks your Bayit language.

  1. Reminders that find you

    Tasks and events arrive with Done and Snooze buttons, and a morning summary of the day.

  2. Just tell it

    By text, photo or voice it adds, moves or completes tasks, events, shopping items and notes. Every change waits for Apply and can be undone.

  3. Changes, told

    When someone moves, renames or deletes something assigned to you, Bayit tells you on Telegram.

Your home. Your keys.

There is no Bayit company server. Each family runs its own copy and brings its own accounts. Keys are encrypted on your server and never sent back to the browser.

  • Your installationCloudflare’s free plan, or Docker on a home computer, NAS, Raspberry Pi or server.
  • Your Google sign-inEach person signs in with Google. A parent invites the others with single-use links.
  • Your AI keyOptional. Claude, OpenAI, Gemini, Grok or any OpenAI-compatible service, paid by you.
  • Your Telegram botOptional. Your own bot, so your family’s messages go only through it.

Install it in an afternoon.

Pick where your family’s Bayit lives. Both run the same app, with the same privacy rules and encryption.

The default: no server to look after, and the free plan is enough for a family. You need a Cloudflare account and a Google sign-in client.

  1. Get the code
    git clone https://github.com/frenkelsergei-blip/bayit.git
cd bayit/app && npm install && npx wrangler login
  2. Create the database, file storage and site
    npx wrangler d1 create bayit-home
npx wrangler r2 bucket create bayit-home-files
npx wrangler pages project create bayit
  3. Add your secrets and deploy
    npx wrangler d1 migrations apply bayit-home --remote
npm run deploy:cloud
Full Cloudflare guide

Run it on anything with Docker (amd64 or arm64): a computer at home, a NAS, a Raspberry Pi 4 or 5, or a small server. Voice messages need Cloudflare for now; everything else works.

  1. Start it
    git clone https://github.com/frenkelsergei-blip/bayit.git
cd bayit && cp .env.example .env
docker compose up -d --build
  2. Look around with sample data
    http://localhost:8080/?demo=1
  3. Give it an https address for Google sign-in and TelegramYour own domain with automatic HTTPS, or a tunnel. The guide walks through both.
