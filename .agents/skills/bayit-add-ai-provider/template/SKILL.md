# My AI provider

Adds **My AI** (OpenAI-compatible chat) to **Settings → Accounts & connections → AI assistant**. It calls only `https://api.my-ai.example`.

## Ask first

- Does the family already have a My AI account and key? The key is pasted by a parent in the app, never in chat or files.

## Apply

```bash
node app/scripts/bayit-extension.mjs apply local-extensions/my-ai
```

## Verify

```bash
node app/scripts/bayit-extension.mjs check
cd app && npm run test:domain && npm run build:cloud
```

Then a parent opens the AI window, chooses My AI, pastes the key, asks one question, and checks that a prepared change still waits for **Apply**.

## Troubleshooting

- "This key was not accepted": the key belongs to another provider or was copied with a space; the parent creates a new one at the keys page.
- No models listed: the account has no credit or the provider changed its model list; check its status page.

Remove it with `REMOVE.md`.
