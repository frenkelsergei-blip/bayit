# My Bank statements

Expenses → Import reads **My Bank** account statement PDFs, with the running balance and the printed closing balance reconciled. It calls no outside address; the PDF is read on the family's own server.

## Ask first

Nothing. The family imports their statements in the app as usual.

## Apply

```bash
node app/scripts/bayit-extension.mjs apply local-extensions/my-bank
```

## Verify

```bash
node app/scripts/bayit-extension.mjs check
cd app && npm run test:domain && npm run build:cloud
```

If the family agrees, they import one real statement in the app and confirm every check shows ✔ and the totals match the paper.

Remove it with `REMOVE.md`.
