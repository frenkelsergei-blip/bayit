# Bayit navigation and loading assets

Brand, family landscape and paper textures generated with the built-in image_gen tool for this Bayit design, 2026-11-07. Original source IDs and derivative hashes are in provenance.json; source files are retained outside the published assets.

UI icons remain Phosphor Icons (MIT); existing OpenMoji assets and licensed Nunito Sans / Heebo font attribution remain in the application’s existing asset licenses. The sketch renderer draws only the loading motifs explicitly requested by the user; the brand and family illustration are actual PNG assets.
